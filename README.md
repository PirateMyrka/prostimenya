# Ви, это Тёма.

Личный сайт-письмо для Вики. Чёрный, фуксия, ч/б цветок, тёмная романтика и маленькое «прости» за поздний ответ. Вдохновлено её аватаркой, без копирования изображения.

## Открыть

Дважды нажми на **`index.html`**. Всё работает без установки программ и без интернета: шрифты и фотография уже в папке.

## Подправить под себя

- Текст письма: `index.html`, блок `<article class="letter-content" id="letter-content">`.
- Остальные надписи: тот же `index.html`.
- Цвета: начало `style.css`, блок `:root`.
- Цветок: `assets/flowers.jpg` — можно заменить своей фотографией, сохранив название.

В письме речь об ответе, который опоздал примерно на 40 минут. Перед отправкой можно подправить текст на свои слова.

## Отправить Ви ссылку

Сайт готов для любого статического хостинга. Загружать нужно **всю папку**, а не только `index.html`. Публикация ещё не выполнена.

`noindex` просит поисковики не индексировать страницу, но не защищает её паролем: опубликованный сайт сможет открыть любой, у кого есть ссылка.

## Что умеет

- Открывает письмо по кнопкам и по нажатию на конверт.
- Закрывает письмо крестиком, клавишей Escape или нажатием вне него.
- Скачивает письмо в текстовый файл.
- Подстраивается под телефон; учитывает настройку уменьшения анимаций.
- Не собирает ответы, не использует аналитику и ничего никуда не отправляет.
